# 手工验收清单

对应《综合优化方案.md》附录 A 各节验收标准。自动化测试（pytest 117 / cargo 14 / vue-tsc）
覆盖记录层与引擎逻辑；本清单为需要真实桌面端 / 真实上游的手工验收项。

## §3.4 改名跳转（6 项）

- [ ] 改名过程中（含清空、中文输入法联想中间态）表单始终编辑同一个服务
- [ ] 改名正在运行的服务：服务不被停掉；「保存并重启」后新名生效、状态圆点正确
- [ ] 名称输入 → 保存 → 重开面板，名称与输入一致
- [ ] 重名/空名校验错误时红字提示指明具体服务（带端口）
- [ ] 改名后历史统计不丢失（service_id 映射 + summary 双查）
- [ ] 删除服务后回到「全部」视图而非第一个服务

## §4.3 模型列表刷新（6 项）

- [ ] 上游新增模型后，≤10 分钟（或点刷新）下拉出现新模型
- [ ] 两个账号同 baseUrl 不同 Key，各自下拉反映各自可用模型
- [ ] 测试 A 账号连通性后，B 服务的模型下拉不受影响
- [ ] 修改账号端点/Key 保存后，下次进入配置页必拉新
- [ ] 拉取失败时下拉仍可用（旧列表 + 过期提示），可继续手输模型名
- [ ] 快速切换服务/账号不出现旧列表闪烁回退

## §5.3 多服务管理（7 项）

- [ ] 排序/搜索定位服务 ≤2 次点击（Ctrl+K 或列表视图）
- [ ] 面板内可完成批量启停/删除（含撤销）
- [ ] 两服务配同端口时保存前即报错
- [ ] 端口被外部进程占用时保存前给出明确提示
- [ ] 有未保存改动时切页有确认弹层；保存按钮高亮
- [ ] 改名/停用不影响运行态识别与统计归档
- [ ] >6 服务自动进入列表视图；排序偏好重启保持

## §6.3 模型白名单（6 项）

- [ ] 配置白名单后 `curl :port/v1/models` 返回全集（default/required 标记）
- [ ] clamp 模式白名单外请求实际发往主模型
- [ ] reject 模式返回 400 且错误体列出可用模型
- [ ] 别名映射生效，统计"按模型"显示对外名
- [ ] 不配置白名单的存量服务行为与升级前一致
- [ ] 多选器可搜索、可全选、主模型锁定不可移除

## §7.6 定价 v2（8 项）

- [ ] 旧 pricing.json 不改文件，与升级前费用一致（golden fixtures 双端固化）
- [ ] `discount: 0.5` 模型费用减半
- [ ] 300K 上下文请求按第二档计价（v1 range 与 v2 upto 均可）
- [ ] 同一模型 21:59 / 22:01 分别按峰/谷价（golden 固定）
- [ ] 周六/周日走周末价
- [ ] 思考 token 按 output_thinking 计价（需上游区分输出）
- [ ] 月免费额度冲抵：额度内请求费用按比例递减至 0
- [ ] 面板费用与引擎 /stats 返回一致（读取端重算同口径）

## §8.6 订阅额度（4 项）

- [ ] local-rolling-5h 服务在统计页看到 5h 窗口用量与重置时刻
- [ ] 断网/上游不可用时降级 local 且标 stale，不影响统计页与代理主流程
- [ ] 新增供应商适配器 = 新文件 + registry 注册一行 + 单测
- [ ] 旧配置 pricing:"none"（含对象形式）费用隐藏、额度卡出现

## §9 热加载

- [ ] 运行中服务改模型 → 保存 → 热加载提示"N 个服务生效"，无需重启
- [ ] 运行中服务改端口 → 热加载后新端口可访问、旧端口关闭
- [ ] 新增/删除服务后热加载，runners 与状态页一致
- [ ] 重载瞬间请求返回 503 + Retry-After（而非连接拒绝）
- [ ] 新配置端口被占用 → 旧配置继续运行，日志有失败原因

## §10 UI 重构

- [ ] 选「近 7 天」后下拉显示"近 7 天"且重启后保持
- [ ] 删除服务后 5s 内可撤销；撤销后位置与选中态恢复
- [ ] 100+ 模型下拉搜索可用、滚动不掉帧
- [ ] 深/浅主题逐页过一遍（重点：额度进度条、白名单多选器、区间下拉）
- [ ] 面板隐藏时网络请求为 0；Ctrl+K / Esc 键盘流可用

## 升级回归

- [ ] 用当月真实 JSONL 跑新旧计价 diff 报告（discount/free_quota 模型除外，其为预期变更）
